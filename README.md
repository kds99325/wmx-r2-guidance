# wmx-r2-guidance

An interactive guide using Jupyter Notebook and Python to easily set up and test the **Movensys WMX R2** ROS 2 EtherCAT motion control environment.

## 📓 Notebooks

1. **Notebook 1 (System Bring-up):** Launch ROS 2 nodes, allocate the WMX3 engine, and initialize EtherCAT communication.
2. **Notebook 2 (Axis Activation):** Clear alarms, execute Servo On, and perform Homing.
3. **Notebook 3 (Motor Control):** Keyboard jogging control and safety stop testing.

## 🛠️ Quick Start

**Prerequisites:** Ubuntu 22.04/24.04, ROS 2 (Humble/Jazzy), WMX3 Engine, JupyterLab

```bash
git clone [https://github.com/kds99325/wmx-r2-guidance.git](https://github.com/kds99325/wmx-r2-guidance.git)
cd wmx-r2-guidance
jupyter lab
```
