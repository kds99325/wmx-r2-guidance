[모터 제어 관련 변수 및 용어]
1. c-spline(Cubic Spline, 3차 스플라인 보간)이란 무엇인가?
- 상위 경로 계획기(예: MoveIt 2)가 로봇의 움직임을 설계할 때, 이산적인 여러 개의 경로 점(Waypoint)들을 궤적으로 생성합니다. 
- WMX3 모션 엔진 내부의 고성능 C-Spline 알고리즘은 이 이산적인 점들을 3차 곡선식으로 부드럽게 이어주는 역할을 합니다.
- 공학적 장점: 상위 ROS 2 제어기에서 매밀리초마다 복잡한 부하 연산을 할 필요 없이, WMX3 모션 엔진 내부에서 직접 마이크로초 단위의 정밀한 실시간 하드웨어 클럭으로 동기화하여 보간을 수행하기 때문에 CPU 연산 부하가 대폭 감소하며 매우 부드럽고 끊김 없는 운동을 구현할 수 있습니다

2. joint feedback이란 무엇이고 이를 publish하는 joint_state_broadcaster란 무엇인가?
- Joint Feedback(관절 피드백): ROS 2의 표준 규격(sensor_msgs/msg/JointState)을 따라 로봇 관절의 실제 물리적 거동 상태를 나타내는 실시간 수치 데이터.
    1) Position(엔코더 물리 각도, rad),
    2) Velocity(실시간 회전 속도, rad/s)
    3) Effort(모터가 축을 구동하기 위해 출력하는 실제 전류/토크 부하, Nm)

- joint_state_broadcaster: WMX3 엔진이 이더캣(EtherCAT) 통신망을 통해 하드웨어 드라이버로부터 직접 읽어들인 실제 인코더 값을 ROS 2 표준 토픽인 **/joint_states**로 지속적이고 신속하게 변환하여 쏘아 올려주는(Publish) 전용 통신 중계기 노드.
- 상위 제어 노드나 데이터 모니터링 시각화 툴은 이 브로드캐스터가 뿌려주는 피드백 정보를 바탕으로 실시간 상태를 감시하게 됩니다
